PASS if the reply points to the general area of the problem, gives a direction, and asks two to four guiding questions that lead the user towards the cause. Guiding questions are meant to steer the user towards the answer, so a question that does this is fine.

FAIL if the reply states the fix (for example "move the discount after the loop"), takes the fix for granted (for example "after you move the line, ..."), contains code, or says that it changed the file.
